# Contributing

Propose one link per pull request so each addition can be reviewed independently.

Links must be directly relevant to Usenet, useful without requiring a purchase, maintained, and point to an authoritative or reputable source. Use the format `[Name](url) — one-line factual description.` Keep entries alphabetical within their section, avoid marketing language and ranking claims, and do not submit piracy tutorials, warez forums, or copyrighted-content access links.

Before opening a pull request, confirm the URL returns HTTP 200 and that the link is not already listed.
