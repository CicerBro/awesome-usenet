# Awesome Usenet [![Awesome](https://awesome.re/badge.svg)](https://github.com/sindresorhus/awesome)

> A curated list of Usenet software, providers, indexers, automation tools, and guides.

Usenet is a distributed discussion and file-distribution system accessed through Network News Transfer Protocol (NNTP) servers. A provider supplies server access, an indexer searches and produces NZB files, and a download client retrieves the articles named by an NZB. This list focuses on legitimate software, services, documentation, and communities, not copyrighted-content access.

## Getting Started

- [SABnzbd Wiki](https://sabnzbd.org/wiki/) - Documentation covering setup, server connections, categories, and NZB-based downloads.
- [TRaSH-Guides](https://trash-guides.info/#getting-started) - Community-maintained guides for configuring the full automation stack, including hardlinks, folder structure, SABnzbd/NZBGet settings, and Sonarr/Radarr quality profiles.
- [r/usenet wiki](https://www.reddit.com/r/usenet/wiki/index/) - Community reference material explaining providers, indexers, retention, and access models.

## Download Clients

- [NZBGet](https://nzbget.com/) - Cross-platform NZB downloader with a web interface and automation integrations.
- [SABnzbd](https://sabnzbd.org/) - Open-source NZB downloader with a web interface, categories, and API access.
- [Usenapp](https://www.usenapp.com/) - macOS newsreader for reading and posting to Usenet discussion groups.

## Automation

- [Bazarr](https://www.bazarr.media/) - Companion application that manages subtitles for Sonarr and Radarr libraries.
- [Lidarr](https://lidarr.audio/) - Music collection manager that can send NZBs to supported download clients.
- [NZBHydra2](https://github.com/theotherp/nzbhydra2) - Meta-search application that queries multiple NZB indexers through one interface.
- [Prowlarr](https://prowlarr.com/) - Indexer manager and proxy for Servarr applications and download clients.
- [Radarr](https://radarr.video/) - Movie collection manager with indexer and download-client integrations.
- [Readarr](https://readarr.com/) - Book collection manager with metadata, indexer, and download-client integrations.
- [Recyclarr](https://github.com/recyclarr/recyclarr) - CLI that syncs TRaSH-Guides settings to Sonarr and Radarr instances.
- [Sonarr](https://sonarr.tv/) - TV-series collection manager with indexer and download-client integrations.
- [TRaSH-Guides](https://trash-guides.info/) - Recommended quality profiles, custom formats, and naming schemes for Sonarr and Radarr.
- [TRaSH-Guides source repository](https://github.com/TRaSH-Guides/Guides) - Source repository for the community-maintained TRaSH-Guides documentation.

## Indexers

- [Tabula Rasa](https://www.tabula-rasa.pw/) - NZB indexer using an invite-based registration model. ([review](https://usenet-reviews.com/indexers/tabula-rasa/))
- [DrunkenSlug](https://drunkenslug.com/) - NZB indexer with periodic registration openings and API access. ([review](https://usenet-reviews.com/indexers/drunkenslug/))
- [DigitalCarnage](https://digitalcarnage.info/) - NZB indexer with periodic registration openings and API access. ([review](https://usenet-reviews.com/indexers/digitalcarnage/))
- [NinjaCentral](https://ninjacentral.co.za/) - NZB indexer using an invite-based registration model.
- [NZBPlanet](https://nzbplanet.net/) - NZB indexer with an open registration option and API access.
- [omgwtfnzbs](https://omgwtfnzbs.me/) - NZB indexer that uses periodic registration openings. ([review](https://usenet-reviews.com/indexers/omgwtfnzbs/))

## Providers & Block Accounts

- [Eweka](https://www.eweka.nl/en) - European Usenet provider offering SSL NNTP access and a trial option.
- [Newshosting](https://www.newshosting.com/) - Usenet provider offering SSL NNTP access and a trial option.
- [NewsGroupDirect](https://newsgroupdirect.com/) - UsenetExpress-backed provider offering subscriptions and block accounts.
- [Usenet.Farm](https://usenet.farm/) - Independent provider offering subscriptions, block accounts, and a trial option. ([review](https://usenet-reviews.com/providers/usenet-farm/))
- [Usenet Prime](https://usenetprime.com/) - UsenetExpress-backed provider offering subscription access. ([review](https://usenet-reviews.com/providers/usenet-prime/))
- [UsenetExpress](https://usenetexpress.com/) - Operator of a U.S.-based Usenet backbone offering subscriptions and block accounts.
